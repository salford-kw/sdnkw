🏠 صور ونصوص الصفحة الرئيسية
لماذا نحتاج رمز GitHub؟
الموقع ثابت بلا سيرفر، فلوحة التحكم ترفع الصور والبيانات مباشرة إلى مستودعك.
  1. افتح github.com/settings/personal-access-tokens
  2. اضغط Generate new token → نوع Fine-grained
  3. في Repository access اختر مستودع الموقع فقط
  4. في Permissions → Repository اجعل Contents = Read and write
  5. انسخ الرمز والصقه بالأسفل
الرمز يُحفظ في متصفحك فقط ولا يُرفع للموقع. لا تفتح اللوحة على جهاز مشترك.
